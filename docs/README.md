# AutoFox 设计与实施文档

AutoFox 是使用 AutoAnt 技术栈构建的桌面视频下载工具：**Svelte 5 + SvelteKit + shadcn-svelte + Tailwind 4 + Tauri 2 + Rust**。

目标不是把 yt-dlp 翻译成 Rust，而是**自研下载引擎 + 可替换的解析后端**。站点适配（提取器）是跟站点前端赛跑的易腐资产，交给上游维护；下载调度、断点续传、队列、UI 是 AutoFox 自己的长期资产。

解析后端通过**统一进程契约**接入。同一份契约下，随包的 `yt-dlp.exe`、用户自备的 Rust AFX-EP/1 CLI、内置 native Rust 后端都是平等的可选项，用户在设置里选，不需要重新编译 AutoFox。Python 仅存在于 yt-dlp 的冻结构建内部，AutoFox 运行期不要求安装 Python；uv 只用于开发者调试 yt-dlp 源码。

## 关键决策摘要

| 决策 | 结论 | 依据 |
|---|---|---|
| 是否移植 yt-dlp 提取器 | **否** | 18.4 万行 / 940 文件 / 1.2 次提交每天，移植即得到无上游的 fork（见 01 §2） |
| 是否自研下载引擎 | **是** | HLS/DASH/Range 有公开规范，是稳定资产（见 01 §3） |
| 后端如何接入 | 进程契约 + 适配档 | 一份契约覆盖 py/rust/未来后端，用户可换可加（见 03 §3）；默认发现同目录 `yt-dlp.exe` |
| 音视频合流 | 随包 `lib/ffmpeg.exe` | 运行期不依赖 PATH；Rust 生态无可靠替代，属已知硬依赖（见 01 §6） |
