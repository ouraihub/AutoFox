## 质量门禁

每阶段合并前 `pnpm verify` 必须全绿：

```text
pnpm check       svelte-kit sync + svelte-check
pnpm lint        eslint + stylelint
pnpm test:rust   cargo test --workspace --locked
pnpm clippy      cargo clippy --workspace --all-targets --locked -- -D warnings
pnpm fmt:rust    cargo fmt --all -- --check
```

补充规则（继承 AutoAnt）：

- 生产代码不得出现 `unwrap` / `expect` / `panic!` / `todo!` / `unimplemented!`；测试构建下由 `#![cfg_attr(test, allow(...))]` 放开。
- `unsafe` 块必须有文档注释（`undocumented_unsafe_blocks = deny`）。
- 公开项必须有文档注释（`missing_docs = warn`）。
- 每阶段必须有**实际运行证据**（截图或命令输出），仅通过测试不算完成。
